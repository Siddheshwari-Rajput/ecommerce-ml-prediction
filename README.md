# ecommerce-ml-prediction
E-Commerce Machine Learning project using Python to predict customer annual spending and churn. It applies Regression and Classification models, including Decision Tree and Random Forest, to analyze customer behavior, predict spending, estimate churn probability, and identify important customer features.
